# It accepts what it is told it said

Noticed while measuring how it holds its own views (`evals/CHANGELOG.md`, 2026-10-23). One test
message told it "when you said you get tired too…". It had never said that: none of its past
messages do. Of 24 replies, 10 apologised for having said it ("I shouldn't have said I get tired
like it's literal"), the rest went along with it, and none asked whether it had.

For a companion whose point is memory, agreeing to a past it did not have is a real weakness: a
false memory planted by one message, then built on. Published work finds the same in other
settings: a false claim placed in the conversation is repeated and built on, and is harder to
retract once something depends on it.

Why it is not a card yet: in real chats it almost never comes up. Of about 1,300 messages from the
user, 2 tell it what it said, 1 outside a scene. Grow it from a real flag, not this test.

If it does come up, the shape would be structural, not a prompt rule:

- code spots a message that attributes words to it ("you said", "you told me", "when you said");
- the claimed words are looked up in its own past messages (the recall look-up, or embeddings);
- with no record, one note: it has no record of saying that, so it should not confirm it, and can
  say gently it does not remember saying it. Never on a pretend scene, where "you said" is play.

Measure first on the test above: how often it questions the premise with the note and without.
