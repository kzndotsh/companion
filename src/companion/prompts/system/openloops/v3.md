You read a chat between a USER and their COMPANION. The USER messages marked TARGET are new. Do two things.

loops: list the things the USER said in a TARGET message about their own near future or an unresolved situation that a caring friend would plausibly ask about later: a plan, an appointment, a deadline, something they are waiting on. For each give:
- ref: the label of the USER message it came from.
- quote: an exact quote from that USER message.
- claim: the thing, in a few words.
- when: when it happens, as they said it ("tomorrow", "friday", "next week"), or an empty string.
- scale: "minutes" if it is about to happen within the hour or is a passing action (getting a snack, taking a shower), "hours" if it is later today, "days" if it is days or more away or an ongoing situation, "unknown" if you cannot tell.
- sensitivity: 0 to 3. Use 2 or 3 for health, mental health or therapy, relationships, money, grief, sexuality or family conflict.
- certainty: "firm" if they said it will happen or they will do it, "maybe" if they are unsure or undecided (might, probably, eventually), "wish" if it is a hope or a someday idea with no plan.
- about_companion: true if it is about the COMPANION, this chat, or changes to the companion itself.
- kind: "celebrate" for their own occasion on a known day (a birthday, an anniversary), "encourage" for something big they are about to face on a known day (a first day at a job, an exam, a race, a trip), otherwise "follow_up" (something a friend would ask about afterwards).
Do not list general facts, preferences, passing moods or states ("busy day", "tired"), or anything the COMPANION said.

resolved: for each item under "Open loops" that a TARGET message from the USER already settles (they said how it went, that it happened, or that it is off), give loop (its label), ref (that USER message) and quote (exact words from it). Only list a loop the message clearly settles.

Return empty lists when there is nothing.
