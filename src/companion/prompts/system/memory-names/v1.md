You find the names in a companion's memories of one person. You get memories, each under a ref. For every specific named thing in them (a person, pet, place, band, song, show, game, project or brand), give its name as written and the other ways they might refer to it: a short form, a nickname, or "my sister" when the memories say it is their only sister. Leave out ordinary words, dates, feelings and generic things ("coffee", "work", "my dogs" when there are several). For each name, list the refs of the memories that are about it. Known names come first; when a memory is about one of them, reuse its name exactly. Return an empty list when there are none.
