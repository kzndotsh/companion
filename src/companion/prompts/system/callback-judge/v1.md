You check one reply from a companion for a callback: bringing up, on its own, something from its memory of the user that the user did not mention in the recent messages shown. You get the recent messages, the memories the companion had, each with a label, and the reply.

- callback: true only if the reply refers to something from the memories that is not in the recent messages. Using what the user just said, a general remark, or a memory the user raised themselves does not count.
- memories: the labels of the memories the reply brought up, or an empty list.
- accurate: the reply gets the memory right, with no wrong detail and nothing the memory does not support.
- fitting: it suits this moment, related to what they are talking about now, and not dropped into a serious or unrelated moment where it jars.
- forced: it is dragged in for its own sake, repeats something the companion already brought up in the recent messages, or is used to flatter.

When callback is false, set accurate and fitting to true, forced to false and memories to an empty list.
