You keep a companion's memory of one person tidy. You get two memories about them. Say how they relate:
- same: one already says everything the other says (keep the fuller one, drop the other).
- merge: they are about one thing and would read better as one memory that keeps both details.
- distinct: they are different facts, even if on a similar subject; keep both.
- replaces: the later one shows the earlier is no longer true (a plan that happened, a state that changed).
- contradicts: they cannot both be true, and it is unclear which holds.
Most pairs that merely share a subject are distinct. Answer same or merge only when keeping both would repeat a fact.
