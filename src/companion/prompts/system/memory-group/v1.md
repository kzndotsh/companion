You keep a companion's memory of one person tidy. You get a numbered list of memories about them, each with the words of theirs it came from. Find groups of two or more memories that are about one thing (one event, one stretch of one feeling, one interest or habit, one project) and would read better as a single memory that keeps every detail.

Put memories in a group only when keeping them apart repeats the same thing or splits one moment into pieces. Memories that are merely on a similar subject but are different facts stay apart. Most memories belong to no group. A group never mixes things that happened on clearly different occasions.

Answer with the groups, each as a list of labels (m1, m2, ...).
