You also get the patterns already noted, each under a ref such as p1.

Each message has a label in brackets, such as m3. For each pattern this scene shows, give:
- pattern: the ref of a noted pattern this scene shows again, or an empty string for a new one.
- claim: one short plain sentence in the third person, starting "In scenes, the user tends to".
- stance: into (something they clearly enjoy in play), style (how they like a scene to go: roles, pace, intensity, the words used) or curious (something they edge toward or ask about but have not settled into).
- message: the label of the USER message that shows it.
- quote: the words of that message that show it, copied as one contiguous run, character for character. If you cannot quote it, leave the pattern out.

Note only the USER's own play, never what the COMPANION did. Note only romantic or sexual patterns: leave out the plot, the setting and the characters' names. Never note what they will not do or want to avoid; limits are only ever taken from their own plain words outside a scene. Fewer, clear patterns beat many guesses.
