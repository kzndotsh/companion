# Basics (J48)

What to call them. Until memory knows their name, a note on a casual turn asks for it (at most
once a day, never while a check-in is offered), and their answer is remembered as a belief quoting
their own words. Live.

| File | What |
|---|---|
| `logic.py` | pure: when to ask, the note, reading a name from their answer, the belief it becomes |
| `run.py` | effects: the note (`name_offer`), the capture once the turn is stored (`capture_name`), `BASICS` |

Its prompts stay in `src/companion/prompts/` (`notes/ask-name`, `system/name-capture`). How they want
to be referred to is a separate setting (`companion address`, `core/turn/address.py`).
