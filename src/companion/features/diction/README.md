# Diction

Its own word and emoji choices: what it avoids and what is its own. Each part is its own folder, read
like a feature, with its own README.

- `tics/`: what its recent replies keep repeating (openers, phrases, pet words, moves), counted by code
  and read by a judge, named in a note so the next reply differs.
- `marks/`: an emoticon or kaomoji of its own, offered now and then on a playful message, never one
  of theirs.

Its standing promises (words it agreed to drop) join diction once the promises review settles them
(kzndotsh/companion#1, 2026-11-17). Mood stays its own feature (ADR 0016). "Habits" is kept for the
owner's routines, never the companion's tics.

The folder was gathered from `features/moves`, `core/turn/habits.py`, `kit/habits.py` and
`features/marks`. Stored names did not change: the `habits` judge, the `habit check` and
`mark: one of its own offered` decision keys, `COMPANION_MARKS` and every prompt file.
